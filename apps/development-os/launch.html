New Project Launch Template

Enter an opportunity and export the same structured phase plan, source map and approval gates. This creates a local review draft only. It does not create sheets, assign staff, send messages or authorize commitments.

Local workspace · Blank reusable specification

New tasks remain Draft. Costs and project deadlines stay unconfirmed.

Launch process

  1. Check the existing project register and aliases. Reuse canonical IDs and existing sources before provisioning.
  2. Validate identity, originals, revision and authority. Found files do not establish approvals.
  3. Choose the relevant tasks below. Confirm planning owners; construction roles are appointed at the release gate.
  4. Prepare scope-based feasibility and cost codes. Missing prices, quantities, yield and funding stay missing.
  5. Review the exact mapped record changes. After approval, write to the existing source/plan/control structure once and read back. Never blind-append duplicates.
  6. Only tasks with an owner, date/follow-up, source, completion test and satisfied dependencies become Ready.

Cost and financial controls

Every package records project/lot/shared-site ID, cost code, scope, drawing basis, quantity/unit, labor/material/equipment/subcontract amount, source/expiry, exclusions, approved budget, commitments, incurred actual, cash paid, remaining commitment, uncommitted forecast and unallocated risk.

EAC = incurred actual + remaining commitments + uncommitted work + unallocated risk. Contributions, capital returns, cash payments and refundable securities stay separate. Shared costs enter consolidated totals once. No pilot-specific prices or partnership terms are embedded.

Specialized AI task brief

Project ID; Task ID; objective; authoritative sources and revisions; human owner; expected result; dependency; approval boundary; definition of done; handoff. Reuse this brief for acquisition, feasibility, legal support, design/permitting, estimating/procurement, schedule, finance and closeout. A role instruction does not create a new autonomous agent.

Activation checks

Identity/duplicate check; source authority; owner; due/follow-up; phase dependencies; permissions; commitment approval; closure evidence. A new address never inherits another project’s prices, terms, staff, areas or deadlines.

Reusable draft specification. Current project systems and original evidence remain authoritative.
