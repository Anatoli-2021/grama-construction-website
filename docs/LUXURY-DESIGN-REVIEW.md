## Included

- Authentic 1847 Dexter Lane photography on desktop and mobile, with the same project credit. The introductory headline describes custom homes and residential development; three paths serve development partners, homeowners and Dexter Acres enquiries.
- A short portfolio strip distinguishes eight entries in the completed-project index from fourteen proposed Dexter Acres homes. No sold-home totals, revenue, prices, availability, approvals or returns are implied.
- An editorial project rail links all eight cases, using existing photographs, native overflow, keyboard access and previous/next controls. Tony, Alina and the existing eleven-logo trusted-partners section remain visible.
- The original Dexter cinematic sequence, reduced-motion alternative and fourteen-lot plan remain intact. Contact readiness/validation/retries and private presentation authorization remain separate server handlers.
- Text responses support negotiated gzip, with correct quality weights and HEAD lengths. Binary media remains unchanged. Compression state is bounded and separates local/hosted HTML.
- Prerendered page metadata, factual business/breadcrumb structured data and a public-page sitemap are included. HTML, host headers and robots.txt keep this review target unindexed. A company-domain indexing launch needs a separate reviewed change.

The existing General Sans TTF is retained unchanged, with system Georgia for editorial headings. No new font conversion or unverified WOFF2 derivative is included. Fontshare's [current license](https://www.fontshare.com/licenses/itf-ffl) permits its stated website uses while imposing separate restrictions on modified font software; this candidate introduces no modified font file.
