# GRAMA Development — proposed identity

This feature branch is a complete identity study for client review. **Do not deploy this rebrand to the client's production website or replace the public identity before Tony's approval.** Grama Construction remains the current public brand; no legal-name change is made by these files.

Run the normal local development/production preview from README. Open `/brand-review` for the identity room and `/` for the proposed website. The visible Brand concept label is intentional. The review route is not confidential access control; it contains only conceptual applications and approved public project materials.

## Three original directions

- **A — Architectural wordmark:** custom-drawn GRAMA letter geometry with a DEVELOPMENT descriptor. Recommended master direction.
- **B — Geometric G:** a compact architectural symbol and lockup for small applications and signage.
- **C — Institutional group:** a heavier GRAMA GROUP study; the name and implied corporate scope require separate confirmation.

The SVGs are in `public/assets/brand/`. Letterforms are original code-native paths, not converted font outlines or copied competitor marks. Descriptor text uses system Arial; no new font is embedded. The existing original General Sans TTF and system Georgia remain the website type pair. Similarity searches, name availability and professional trademark review remain pending; no clearance is claimed.

## Identity applications

The review room includes concept applications for the corporate website, development page, investor presentation, architectural brochure, business cards, letterhead, email signature, social media, construction-site board, development-site board, property marketing sheet, project cover and digital advertisement. Each is labelled CONCEPT. Public contact details and actual approved project photography are used; Dexter imagery stays labelled as an architectural visualization of a proposed project.

The proposed homepage has three audience paths, selected work and a Dexter Acres introduction. The dedicated Dexter page adds an editorial concept overview and links to the existing cinematic chapter, 14-lot map and supplied plan. No availability, approvals, dates, prices or returns are invented. Existing cases, family/partner content, Contact validation and protected presentation handlers remain intact.

## Release gate

Commit/push and an owner-reviewed PR are part of concept delivery. Deployment, a public identity replacement, legal-name changes, paid assets, social publication, live enquiry activation and company-domain changes require their applicable approval. Earlier authorization for other website review changes is not approval to launch this proposed rebrand. Contact provider setup remains separate; see CONTACT-DELIVERY.md.

The PR records exact test results, responsive evidence and any unrun checks. Review the logo, audience order, project wording and applications with Tony before treating this direction as final.
